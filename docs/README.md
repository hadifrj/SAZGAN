# Documentation

This directory contains the stable documentation needed to develop, operate and maintain Sazgan.

- `architecture.md` — application structure and boundaries
- `development.md` — coding, testing and release workflow
- `operations.md` — startup, LAN access, diagnostics, deployment and updates
- `database.md` — persistence and migrations
- `security.md` — security controls and production checklist
- `features.md` — functional specifications
- `user-guide.md` — end-user workflows

Release history is maintained in the root `CHANGELOG.md`; current release metadata is stored in `VERSION`, `RELEASE.json` and `BUILD_INFO.json`.

Documentation should describe the current system and durable decisions. Temporary investigation notes, generated reports and development-stage artifacts do not belong here.
