# User Guide

## Sign in

Open the server address in a browser. The system administrator provides user accounts and passwords.

## Main roles

- **Reception:** requests, status changes, settings, finance and reports
- **Factory technician:** internal repair workflow and technician reports
- **Representative:** external repair, installation and inspection
- **Quality control:** QC reports and testing workflow

Actual permissions are controlled by the application's access settings.

## Service workflow

A typical internal repair flow is:

Reception → initial inspection → parts request → repair → quality control → return/shipping

## Search

The search area supports common service identifiers such as serial number, customer name, reception number and invoice.

## Notifications

The notifications area shows events related to assigned cases and supported communication workflows.

## Backup

Administrators can use the application's backup area and configure the appropriate storage location in company settings.

## Mobile and LAN access

When the server is available on the local network, open the server's LAN address from a phone or another computer on the same network.
