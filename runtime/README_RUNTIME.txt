SAZGAN Python Runtime Bundle

Required runtime: CPython 3.11.9 x64 for Windows.
Official source:
https://www.python.org/ftp/python/3.11.9/python-3.11.9-amd64.exe

For a fully offline installation, place the official installer above as:
runtime\python-3.11.9-amd64.exe

The Server Wizard will:
- use an existing Python 3.11 installation when available;
- otherwise use the bundled installer when present;
- otherwise, in Online/Auto mode, download it from python.org.

Do not replace this runtime with an untrusted build.
